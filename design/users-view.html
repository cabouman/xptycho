The User's View

The scripts a user writes, one per use, and every public name in one place. The three objects are those of the objects page; the helper functions and the Scan methods are listed here for the first time. Written before the code, so that the code is written to match the scripts and not the other way around.

1. The scripts

Simulate and reconstruct with a known probe (demo 1, TCI 2023 Fig. 6)

import xptycho

truth = xptycho.demo_truth('synthetic')             # truth.object, truth.probe, truth.pixel_size, from the demo data archive
positions = xptycho.scan_positions(grid=(12, 12), step=1.02e-6, max_offset=0.3e-6, seed=0)

model = xptycho.PtychoModel(energy=8.8, detector_distance=2.0, detector_pixel=75e-6,
                            frame_size=256, positions=positions, probe_modes=1)
scan = model.simulate(truth.object, truth.probe, pixel_size=truth.pixel_size, peak_photons=1e4, seed=0)
print(scan.summary())

model.set_params(object_data_fit=0.6, probe_weight_exponent=1.25, relaxation=0.5)
model.print_params()
recon = model.recon(scan, probe=truth.probe, iterations=100)
print(recon.summary())
recon.show('./output/demo_1', compare_to=truth)
recon.save('./output/demo_1')

The detector distance and pixel are chosen so the model's object pixel equals the truth's pixel size. simulate compares the pixel_size it is given with the model's and refuses a mismatch, naming both values.

Preprocess measured data, then reconstruct blind with two modes (demo 2, TCI 2025)

Two scripts, because preprocessing is done once and reconstruction many times.

# script one: raw file to scan file
path = xptycho.fetch('goldballs_cxi')                                # entry 65 of the CXI database, cxidb.org; downloaded once
scan = xptycho.preprocess(path, dark='mean_of_dark_frames', crop=512, apodization='tukey',
                          energy=1.0, detector_distance=0.112)         # positions and detector pixel come from the file
print(scan.summary()); scan.show('./output/goldballs')
scan.save('goldballs.h5')

# script two: reconstruct
scan = xptycho.Scan.load('goldballs.h5')
model = xptycho.PtychoModel.from_scan(scan, probe_modes=2)
model.set_params(object_data_fit=0.5, probe_data_fit=0.6, probe_weight_exponent=1.25,
                 relaxation=0.5, mode_schedule=[20], initial_probe_distance=0.3e-6)
recon = model.recon(scan, iterations=200)                            # probe not given: estimated
recon.show('./output/goldballs'); recon.save('./output/goldballs')

Several GPUs

model.configure_devices(num_devices=4)                               # default: every GPU present
recon = model.recon(scan, iterations=200)                            # the same call; the positions are divided among the GPUs

Continue a finished run, and refine positions

scan = xptycho.Scan.load('goldballs.h5')
model = xptycho.PtychoModel.from_scan(scan, probe_modes=2)
recon = xptycho.Reconstruction.load('./output/goldballs')
new_pos, misfit = model.refine_positions(scan, recon.object, recon.probe, max_shift=1)
model.set_params(positions=new_pos)
recon = model.recon(scan, init=recon, iterations=100)

The forward model alone

amplitudes = model.forward(recon.object, recon.probe)                # (J, Np, Np), no noise
print(model.data_error(scan, recon.object, recon.probe))

2. Every public name

namewhat it is
Scanthe measurement: frames, recorded positions, instrument facts. Scan.load(path), scan.save(path), scan.summary(), scan.show(dir), scan.positions, scan.num_frames, scan.frame_shape
PtychoModelthe parameters and the forward model; the objects page, section 2, lists every method
Reconstructionwhat recon returns: object, probe, pixel_size, origin, coverage, positions, mode_energies, params, curves; summary(), show(), save(), Reconstruction.load()
demo_truth(name)a record with object, probe, and pixel_size, read from the demo data archive (downloaded once); for simulation and for compare_to=
scan_positions(grid, step, max_offset, seed)positions of a rectangular scan with random offsets, in meters
fetch(name)download a named public dataset once; returns the local path of the raw file
preprocess(path, dark, crop, apodization, **facts)a raw file to a Scan. dark is a dark frame array, or 'mean_of_dark_frames' to average the dark frames the file holds. crop is the frame size kept about the beam center. apodization='tukey' multiplies each frame by a Tukey window (flat in the middle, tapering to zero at the edge). Instrument facts the file lacks are given as keywords.
nrmse(image, truth, coverage=None)error after removing one complex scale; with coverage (the Reconstruction's map of where the probe reached) only covered pixels count

3. Open points

  1. Laminography series. One model per scan (positions differ per tilt), with the series handled by a loop in the user's script, or one object holding all of them. Claude's view: one model per scan in version 1; a series object only if the loop proves awkward.
  2. demo_truth returns a record (object, probe, pixel_size) that compare_to= takes directly, as written above. Confirm.
  3. Units of energy: keV, as in the papers and the old configs.

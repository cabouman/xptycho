The User's View

The scripts a user writes, one per use, and every public name in one place. The three objects are those of the objects page; the helper functions and the Scan methods are listed here for the first time. Written before the code, so that the code is written to match the scripts and not the other way around.

1. The scripts

Simulate and reconstruct with a known probe (demo 1, TCI 2023 Fig. 6)

import xptycho as xpt

TRUTH_URL = 'https://www.datadepot.rcac.purdue.edu/bouman/data/demo_xptycho_synthetic.h5'
truth = xpt.Sample.load(xpt.download(TRUTH_URL, './demo/input'))   # a Sample: truth.object, truth.probe, truth.pixel_pitch
positions = xpt.scan_positions(grid=(12, 12), step=1.02e-6, max_offset=0.3e-6, seed=0)

model = xpt.PtychoModel(energy=8.8, detector_distance=2.0, detector_pitch=75e-6,
                        frame_size=256, positions=positions, probe_modes=1)
scan = model.simulate(truth, peak_photons=1e4, seed=0)
print(scan.summary())

model.set_params(object_data_fit=0.6, probe_weight_exponent=1.25, relaxation=0.5)
model.print_params()
recon = model.recon(scan, probe=truth.probe, iterations=100)
print(recon.summary())
figures = xpt.view_sample(recon, compare_to=truth)
xpt.save_figures(figures, './output/demo_1')
recon.save('./output/demo_1/recon.h5')

The detector distance is chosen so the model's object pixel equals the truth's pixel pitch. simulate compares the sample's pixel_pitch with the model's and refuses a mismatch, naming both values.

Preprocess measured data, then reconstruct blind with two modes (demo 2, TCI 2025)

Two scripts, because preprocessing is done once and reconstruction many times.

# script one: raw file to scan file
path = xpt.fetch('goldballs_cxi')                                    # entry 65 of the CXI database, cxidb.org; downloaded once
scan = xpt.preprocess(path, dark='mean_of_dark_frames', crop=512, apodization='tukey',
                      energy=1.0, detector_distance=0.112)         # positions and detector pitch come from the file
print(scan.summary()); xpt.view_scan(scan)
scan.save('goldballs.h5')

# script two: reconstruct
scan = xpt.Scan.load('goldballs.h5')
model = xpt.PtychoModel.from_scan(scan, probe_modes=2)
model.set_params(object_data_fit=0.5, probe_data_fit=0.6, probe_weight_exponent=1.25,
                 relaxation=0.5, mode_schedule=[20], initial_probe_distance=0.3e-6)
recon = model.recon(scan, iterations=200)                            # probe not given: estimated
xpt.view_sample(recon, region=VIEW_REGION); recon.save('./output/goldballs/recon.h5')

Several GPUs

model.configure_devices(num_devices=4)                               # default: every GPU present
recon = model.recon(scan, iterations=200)                            # the same call; the positions are divided among the GPUs

Continue a finished run, and refine positions

scan = xpt.Scan.load('goldballs.h5')
model = xpt.PtychoModel.from_scan(scan, probe_modes=2)
recon = xpt.Sample.load('./output/goldballs/recon.h5')
new_pos, misfit = model.refine_positions(scan, recon.object, recon.probe, max_shift=1)
model.set_params(positions=new_pos)
recon = model.recon(scan, init=recon, iterations=100)

The forward model alone

amplitudes = model.forward(recon.object, recon.probe)                # (J, Np, Np), no noise
print(model.data_error(scan, recon.object, recon.probe))

2. Every public name

namewhat it is
Scanthe measurement: frames, recorded positions, instrument facts. Scan.load(path), scan.save(path), scan.summary(), scan.positions, scan.num_frames, scan.frame_shape
PtychoModelthe parameters and the forward model; the objects page, section 2, lists every method
Samplean object and the probe it was seen with; a ground truth or what recon returns: object, probe, pixel_pitch, origin, name, mode_energies, and run for an estimate (run.parameters, run.data_error, run.iterations, run.positions, run.coverage); summary(), save(path), Sample.load(path)
view_scan(scan), view_sample(sample, region, compare_to, compare_label)viewing, separate from the objects: each makes figures, puts them on the screen, and returns them. region is the part of the object to show, chosen in the script; with none given, the rectangle spanned by the probe centers. The windows zoom and pan with the mouse.
save_figures(figures, directory)write the figures a view returned to PNG files
download(url, directory)download a file into a directory unless it is already there; returns the local path
scan_positions(grid, step, max_offset, seed)positions of a rectangular scan with random offsets, in meters
fetch(name)download a named public dataset once; returns the local path of the raw file
preprocess(path, dark, crop, apodization, **facts)a raw file to a Scan. dark is a dark frame array, or 'mean_of_dark_frames' to average the dark frames the file holds. crop is the frame size kept about the beam center. apodization='tukey' multiplies each frame by a Tukey window (flat in the middle, tapering to zero at the edge). Instrument facts the file lacks are given as keywords.
nrmse(image, truth, region=None)error after removing one complex scale; with a region (for example recon.scanned_region()) only the pixels inside it count

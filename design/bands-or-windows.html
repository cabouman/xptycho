Bands or Windows

Two ways to shard the object image across the GPUs. Both are drawn on the same small example: an image of 56 rows, 6 scan lines of 16-row patches, 3 GPUs with 2 scan lines each. Colors: GPU 0 blue, GPU 1 green, GPU 2 purple.

What is the same in both. Each GPU holds its own block of positions, and those arrays never move. Each GPU's patches touch a range of image rows, its window: rows 0–23, 16–39, and 32–55. Neighboring windows overlap, because patches overlap. The question is only who holds which image rows, and what moves when a sum over all positions is formed.

A. Bands with owners

On the computing page now. mbirtorch's pattern.
  1. The image rows are cut into three equal bands. Each band has one owner.
  2. Each GPU adds its patches into its window.
  3. Sum to owner: the part of a window that lies in another GPU's band (dark) is sent to that owner, which adds it in.
  4. Each owner computes the result for its band.
  5. Copy to window: the same rows come back, so each GPU has the result over its whole window.

B. Windows only

Vera's proposal. No bands, no owners.
  1. Each GPU holds only its window. Nothing else is defined.
  2. Each GPU adds its patches into its window.
  3. Exchange overlaps: where two windows overlap (dark), the two GPUs send each other their sums for those rows and add them. Both now hold the complete sum there.
  4. Each GPU computes the result on its own window. Nothing comes back, because nothing went away.

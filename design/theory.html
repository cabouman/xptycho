PMACE Algorithm Structure

The PMACE algorithm, organized by the kinds of quantities it uses, before any code. The derivation is in the two TCI papers (2023, known probe; 2025, blind multi-mode); the algorithm as run is Qiuchen Zhai's ptycho_pmace, which fills in what the papers leave out, and this page follows the code wherever the two differ and says so. The 2023 case is \(K=1\) with the probe held fixed, so this is one algorithm.

1. The quantities

There are five kinds. They differ in who sets them and how long they live. The names fmodel_params and recon_params are the mbirtorch split: the first specifies the forward model, the second specifies the reconstruction.

Measured data

Fixed for the whole run. Never modified.
  • \(y_j\), one per scan position \(j = 0,\dots,J-1\): the measured amplitude, an \(N_p \times N_p\) real array. It is the square root of the detector counts. (Dark subtraction and bad-pixel masking are preprocessing; the papers do not discuss them.)

The data file also records the scan positions and the instrument facts. Those are forward-model parameters that happen to be read from the file.

Forward-model parameters (fmodel_params)

Specify the forward model \(A\). Read from the data file or given. Never estimated in version 1.
  • Wavelength (or energy), object-to-detector distance, detector pixel pitch, frame size \(N_p\).
  • The scan positions, in meters.
  • \(K\), the number of probe modes the model ends with: not a physical fact, but part of the assumed model. A blind run starts with one mode and reaches \(K\) on the mode schedule.

From these the model derives the object pixel pitch, \(\lambda L / (N_p \Delta_{\mathrm{det}})\) with \(L\) the detector distance (standard far-field sampling; not stated in the papers), the positions in pixels, and so the patch operators \(P_j\). Far-field propagation is a fixed assumption of the model, not a parameter.

Unknowns

The inputs of the forward model. Given, or estimated by the run.
  • \(x\): the object, \(N_1 \times N_2\) complex transmittance. Always an output.
  • \(d_k\), \(k = 0,\dots,K-1\): the probe modes, each \(N_p \times N_p\) complex. Given and held fixed in the 2023 paper; estimated, and then also an output, in the 2025 paper. The same kind of thing either way.

In the equations \(D_k = \mathrm{diag}(d_k)\) is multiplication by probe mode \(k\). It is the unknown written as a matrix, not an operator of the instrument.

Reconstruction parameters (recon_params)

Chosen by the user. Specify the reconstruction, not the physics.
  • \(\alpha_1\): object data-fit weight. \(\alpha_2\): probe data-fit weight.
  • \(\kappa \in [1,2]\): exponent on \(|d_k|\) in the averaging weights.
  • \(\rho \in (0,1)\): the Mann step.
  • The number of iterations.
  • The mode schedule: the iterations at which a new mode is added, and the energy fraction \(f\) a new mode gets (section 5).
  • The Fresnel propagation distance used to initialize the probe and to add a mode (sections 4 and 5).
  • The object grid: its shape, which must hold every patch. The counterpart of recon_shape in mbirtorch.
  • (\(\varepsilon\) in a stable inverse is a fixed formula, \(10^{-6}\sqrt{\|a\|^2/\dim a}\) for the array \(a\) being inverted, not a choice.)

Run state

Exists only during the run. Discarded after. The user never sees it.
  • \(\mathbf{v} = [v_0,\dots,v_{J-1}]\): one complex \(N_p \times N_p\) patch per scan position, each position's own copy of its part of the object. The same size as the data.
  • When the probe is estimated: \(\mathbf{s}_k = [d_{0,k},\dots,d_{J-1,k}]\), each position's own copy of mode \(k\). Also the size of the data, once per mode.
  • The other Mann variables: \(\mathbf{w}, \mathbf{z}\) (patches) and \(\mathbf{r}_k, \mathbf{u}_k\) (probes). Not all are temporary: \(\mathbf{z}\) is used by the probe step of the same iteration, and \(\mathbf{u}_k\) is the probe the next iteration's image step uses.

PMACE is a consensus method: every scan position holds its own copy of what it can see, and the unknowns are the consensus of the copies. Neither unknown is state. At the end, \(\hat x\) is the weighted average of the \(v_j\) and \(\hat d_k\) is the mean of the \(d_{j,k}\). Inside the loop the unknowns themselves never appear: the consensus values the steps use are \(\mathbf{z}\) (patches of the average of \(2\mathbf{w}-\mathbf{v}\)) and \(\mathbf{u}_k\), which equal the unknowns only at the fixed point.

Not on this page: compute settings (devices, batch size). They change where the arithmetic runs and never the answer. They would be a sixth kind, compute_params, kept separate as mbirtorch keeps them.

2. The forward model and the operators

The forward model is a function of the unknowns, specified by the forward-model parameters:

\[ y_j = \sqrt{\mathrm{Pois}\Big(\sum_{k=0}^{K-1} \big|\mathcal{F} D_k P_j x\big|^2\Big)} \]

Here \(P_j\) cuts patch \(j\) out of the object (from the positions and the pixel pitch), \(D_k = \mathrm{diag}(d_k)\) multiplies by probe mode \(k\), and \(\mathcal{F}\) is the orthonormal 2D DFT, the far-field propagation to the detector. The modes add in intensity, and the detector counts \(I_j = y_j^2\) are Poisson. Everything the algorithm does is built from these pieces and the four steps below.

Building blocks \(P_j^T\) adds a patch back into the image at position \(j\); \(\mathcal{F}^*\) is the inverse DFT. A stable inverse of any array \(a\) is \(a^* / (|a|^2 + \varepsilon)\) with \(\varepsilon = 10^{-6}\sqrt{\|a\|^2/\dim a}\); it is written \(D_{k,\varepsilon}^{-1}\), \(X_{j,\varepsilon}^{-1}\), \(\Lambda_{k,\varepsilon}^{-1}\) below. \(\Lambda_k = \sum_j P_j^T |D_k|^\kappa P_j\): the coverage map, an image-sized diagonal. \(w_k = \|d_k\|^2 / \sum_m \|d_m\|^2\): the energy weight of mode \(k\). In a blind run \(\Lambda_k\) and \(w_k\) are computed from the current consensus modes and change every iteration.
Patch data-fit step \(F^I_j\) one patch in, one patch out; uses only \(y_j\), \(v_j\), and the consensus modes \(d_k\) \[\tilde v_{j,k} = D_{k,\varepsilon}^{-1}\,\mathcal{F}^*\!\left( y_j \circ \frac{\mathcal{F} D_k v_j}{\sqrt{\sum_m |\mathcal{F} D_m v_j|^2}} \right), \qquad F^I_j(v_j) = (1-\alpha_1)\, v_j + \alpha_1 \sum_k w_k\, \tilde v_{j,k}\]
Patch averaging step \(\mathbf{G}^I\) all patches in, all patches out, through the image. The division by \(\Lambda_k\) is the stable inverse, so a pixel no probe reaches comes out zero and a dimly lit pixel is damped. The object grid is a given shape and may include pixels no patch reaches; those stay zero. \[\bar x(\mathbf{v}) = \sum_k w_k\, \Lambda_{k,\varepsilon}^{-1} \sum_j P_j^T |D_k|^\kappa v_j, \qquad (\mathbf{G}^I \mathbf{v})_j = P_j\, \bar x(\mathbf{v})\]
Probe data-fit step \(F^P_{j,k}\) uses the patch \(p_j = P_j \bar x\) of the current average image, \(y_j\), this position's own copy \(d_{j,k}\) for the phase, and the consensus modes \(d_m\) for the amplitude. (The papers write the denominator with the per-position copies and pass \(\mathbf{z}\) for the patch; the code does as written here.) \[\tilde d_{j,k} = X_{j,\varepsilon}^{-1}\,\mathcal{F}^*\!\left( y_j \circ \frac{|\mathcal{F} X_j d_k|}{\sqrt{\sum_m |\mathcal{F} X_j d_m|^2}} \circ \frac{\mathcal{F} X_j d_{j,k}}{|\mathcal{F} X_j d_{j,k}|} \right), \quad X_j = \mathrm{diag}(p_j), \qquad F^P_{j,k}(d_{j,k}) = (1-\alpha_2)\, d_{j,k} + \alpha_2\, \tilde d_{j,k}\]
Probe averaging step \(\mathbf{G}^P\) the plain mean over positions, returned as \(J\) identical copies so the Mann update can subtract per position \[\bar d_k = \frac{1}{J} \sum_j d_{j,k}\]
Outlier replacement after each mode's Mann update, per pixel: copies far from the mean are replaced by it; a mean deviation of zero is replaced by \(10^{-6}\) (process_probe_arr; not in the papers) \[ d_k \leftarrow \tfrac{1}{J}\textstyle\sum_j s_{j,k}, \qquad s_{j,k} \leftarrow d_k \ \text{ wherever } \ 0.6745\,\frac{|s_{j,k} - d_k|}{\mathrm{mean}_j |s_{j,k} - d_k|} > 1.5 \]

4. Initialization

As the code does it (gen_init_probe, gen_init_obj). The probe first, from the mean back-transformed data, propagated a chosen distance \(z\) by Fresnel propagation \(U\) at the wavelength \(\lambda\) and the object pixel pitch \(\Delta_x\), then smoothed by a Gaussian low-pass filter \(S\) with \(\sigma = 1\) pixel on the real and imaginary parts. This is the only place Fresnel propagation appears; the forward model is far-field throughout, and \(z\) is a reconstruction parameter.

\[ d^{(0)} = S\left\{ U_{\lambda,z,\Delta_x}\left\{ \frac{1}{J}\sum_j \mathcal{F}^* y_j \right\} \right\} \]

Then the object, real-valued, so that each patch has the right scale: a constant patch of value \(\sqrt{\|y_j\| / \|d^{(0)}\|}\) per position, averaged over the coverage, pixels no patch reaches set to the median, then the same filter on the magnitude.

\[ x^{(0)} = S\left\{ \left| \Lambda_{0,\varepsilon}^{-1} \sum_j P_j^T \left( \sqrt{\frac{\|y_j\|}{\|d^{(0)}\|}}\; \mathbf{1} \right) \right| \right\}, \qquad \Lambda_0 = \sum_j P_j^T P_j \]

The run state starts as copies: \(v_j^{(0)} = P_j x^{(0)}\), with \(\mathbf{w} = \mathbf{z} = \mathbf{v}\), and \(\mathbf{r}_0 = \mathbf{s}_0 = \mathbf{u}_0\) all \(J\) copies of \(d^{(0)}\). A blind run starts with one mode.

5. Adding probe modes

A blind run reaches \(K\) modes by adding one at each iteration of the mode schedule (a reconstruction parameter; the 2025 paper's two-mode runs add the second mode at iteration 20). The addition happens after the image pass of that iteration and before its probe pass, as the code does (add_probe_mode). With \(E = \sum_k \|d_k\|^2\) the total probe energy before the addition and \(f = 0.05\) the energy fraction of a new mode:

  1. Residual intensity, per position, from the consensus modes and the patches of the current average image, clipped at zero: \[ I^{\mathrm{res}}_j = \max\!\Big(0,\; I_j - \sum_{k
  2. The new mode: back-transform the residual amplitude, divide by the patch, average over positions, Fresnel propagate as in the initialization: \[ d_K = U_{\lambda,z,\Delta_x}\left\{ \frac{1}{J} \sum_j X_{j,\varepsilon}^{-1}\, \mathcal{F}^* \sqrt{I^{\mathrm{res}}_j} \right\}, \qquad X_j = \mathrm{diag}(p_j) \]
  3. Scale it to the fraction \(f\) of the total energy: \(d_K \leftarrow d_K \cdot \sqrt{f E} / \|d_K\|\).
  4. Its per-position copies \(\mathbf{s}_K\) are \(J\) identical copies of \(d_K\).
  5. Rescale everything: every mode \(d_k\) and every copy \(s_{j,k}\), \(k = 0 \ldots K\), is divided by \(\sqrt{1+f}\), so the total energy is \(E\) again.
  6. \(K \leftarrow K+1\). The energy weights \(w_k\) follow from the new modes.

Orthogonal modes, optional (orthogonalize_modes, off by default; orthogonalize_images in the code). Right after the addition, the modes are replaced by an orthogonal set. With the modes as the columns of a matrix \(D = [d_0 \cdots d_{K-1}]\) and its singular value decomposition \(D = U S V^H\), the new modes are the columns of \(U S\), in order of decreasing energy, and every per-position copy \(s_{j,k}\) is set to the new \(d_k\). Since \(U S = D V\) with \(V\) unitary, the new modes predict the same intensities \(\sum_k |\mathcal{F} D_k p_j|^2\) as the old ones. The 2025 paper's software uses this step in the two-mode reconstruction of the gold-ball data and not in the synthetic experiments.

6. The facts that matter for code

  1. Every pass is local, global, local. The local steps need only their own \(y_j\), their own state row, and the current consensus. The global step is one sum over \(j\). This is what lets the data stream through in batches and across GPUs without changing the answer, provided the order within an iteration (the image pass, the averaging, then each mode's pass in turn) is kept.
  2. The state is as large as the data, times \((1+K)\), and the peak is higher. As the algorithm is written, \(\mathbf{v}\), \(\mathbf{w}\), \(\mathbf{z}\) are alive together, and so are \(\mathbf{s}_k\) and \(\mathbf{r}_k\) for each mode. The old code keeps all of it in memory at once. For integrated-circuit scans that is what does not fit, so where the per-position state lives is the first design question, not an afterthought.
  3. The averaging step is scatter-add, divide by coverage, gather. Nothing else touches the whole image. \(\Lambda_k\) is itself a scatter-add of \(|d_k|^\kappa\), recomputed every iteration in a blind run. The iteration does this averaging twice: once on \(2\mathbf{w}-\mathbf{v}\) for the Mann step, once on the updated \(\mathbf{v}\) for the reported image and the probe step.
  4. The probe pass has two global reductions per mode: the mean of the copies, and the per-pixel deviation statistic for outlier replacement, which needs the mean first. Mode addition is one more: the mean of the back-transformed residuals.
  5. The forward model is fixed by the forward-model parameters alone. \(P_j\) comes from the positions and the pixel pitch; \(\mathcal{F}\) is the far-field assumption. The unknowns \(x\) and \(d_k\) are its inputs. Everything else in the algorithm is arithmetic on patches.

8. Where this stands

Settled on 2026-10-03: the five kinds above, with \(K\) a forward-model parameter. The measured data stands alone and is never modified. The run state is internal to the reconstruction and the user never sees it. The probe is an unknown, not part of the physics. The forward model is far-field only; Fresnel propagation appears only in the probe initialization and in adding a mode. Where the papers are silent or differ from the code, the algorithm is the code, as documented in sections 2 to 5; each such point may be revisited after the number-for-number match with the old code, and measured.

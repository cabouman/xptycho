======
Design
======

xptycho was designed before it was written.  The design is a set of web pages kept in the
``design`` folder of the repository and published at
`cabouman.github.io/xptycho <https://cabouman.github.io/xptycho/>`__.

.. list-table::
   :header-rows: 1
   :widths: 24 76

   * - Page
     - What it settles
   * - Theory
     - The PMACE algorithm as it is run, organized by the kinds of quantities it uses.
   * - Objects and data
     - The three objects, what each holds, and every method.
   * - Computing
     - How a reconstruction is divided among the GPUs of a node, and the measured agreement
       with the reference code.
   * - The user's view
     - The scripts a user writes, and every public name.

What the algorithm in the two TCI papers (2023, known probe; 2025, blind multi-mode) is made of, organized by the kinds of quantities it uses, before any code. The 2023 algorithm is the special case \(K=1\) with the probe held fixed, so this page describes one algorithm.

1. The quantities

There are four kinds. They differ in who sets them and how long they live.

Measured data

Fixed for the whole run. Never modified.
  • \(y_j\), one per scan position \(j = 0,\dots,J-1\): the measured amplitude, an \(N_p \times N_p\) real array. It is the square root of the detector counts after dark subtraction and masking.
  • The scan positions. They define \(P_j\), the operator that cuts patch \(j\) out of the object.
  • Instrument facts (wavelength, distance, detector pitch). The algorithm never uses them. They convert positions from meters to pixels and give the pixel pitch of the answer.

Unknowns

Estimated by the run. What comes out.
  • \(x\): the object, \(N_1 \times N_2\) complex transmittance. The output.
  • \(d_k\), \(k = 0,\dots,K-1\): the probe modes, each \(N_p \times N_p\) complex. Known and fixed in the 2023 paper; estimated in the 2025 paper.

Design parameters

Chosen by the user. Never estimated.
  • \(\alpha_1\): object data-fit weight. \(\alpha_2\): probe data-fit weight.
  • \(\kappa \in [1,2]\): exponent on \(|d_k|\) in the averaging weights.
  • \(\rho \in (0,1)\): the Mann step.
  • \(K\): the number of modes, the iteration at which each new mode is added, and the energy fraction a new mode gets.
  • The number of iterations.
  • (\(\varepsilon\) in the stable inverse is a fixed formula, \(10^{-6}\sqrt{\|d\|^2/\dim d}\), not a choice.)

Run state

Exists only during the run. Discarded after.
  • \(\mathbf{v} = [v_0,\dots,v_{J-1}]\): one complex \(N_p \times N_p\) patch per scan position. This is the PMACE state. It is the same size as the data.
  • Blind case only: \(\mathbf{s}_k = [d_{0,k},\dots,d_{J-1,k}]\): one probe estimate per position, per mode. Also the size of the data, once per mode.
  • Temporaries \(\mathbf{w}, \mathbf{z}\) (patches) and \(\mathbf{r}_k, \mathbf{u}_k\) (probes).

The object \(x\) is not state. It is computed from \(\mathbf{v}\) by the weighted average whenever it is needed, and that same average is the final answer.

2. The operators

Building blocks first, then the four steps the iteration is made of.

Building blocks \(P_j\) cuts out patch \(j\); \(P_j^T\) adds a patch back into the image at position \(j\). \(\mathcal{F}, \mathcal{F}^*\): the orthonormal 2D DFT and its inverse. \(D_k = \mathrm{diag}(d_k)\), with stable inverse \(D_{k,\varepsilon}^{-1} = \mathrm{diag}\big(d_k^* / (|d_k|^2 + \varepsilon)\big)\). \(\Lambda_k = \sum_j P_j^T |D_k|^\kappa P_j\): the coverage map, an image-sized diagonal; it changes whenever the probe changes. \(w_k = \|d_k\|^2 / \sum_m \|d_m\|^2\): the energy weight of mode \(k\).
Patch data-fit step \(F^I_j\) one patch in, one patch out; uses only \(y_j\), \(v_j\), and the modes \[\tilde v_{j,k} = D_{k,\varepsilon}^{-1}\,\mathcal{F}^*\!\left( y_j \circ \frac{\mathcal{F} D_k v_j}{\sqrt{\sum_m |\mathcal{F} D_m v_j|^2}} \right), \qquad F^I_j(v_j) = (1-\alpha_1)\, v_j + \alpha_1 \sum_k w_k\, \tilde v_{j,k}\]
Patch averaging step \(\mathbf{G}^I\) all patches in, all patches out, through the image \[\bar x = \sum_k w_k\, \Lambda_k^{-1} \sum_j P_j^T |D_k|^\kappa v_j, \qquad (\mathbf{G}^I \mathbf{v})_j = P_j\, \bar x\]
Probe data-fit step \(F^P_{j,k}\) uses the consensus patch \(z_j\), \(y_j\), and all modes at position \(j\) \[\tilde d_{j,k} = X_{j,\varepsilon}^{-1}\,\mathcal{F}^*\!\left( y_j \circ \frac{\mathcal{F} X_j d_{j,k}}{\sqrt{\sum_m |\mathcal{F} X_j d_{j,m}|^2}} \right), \quad X_j = \mathrm{diag}(z_j), \qquad F^P_{j,k}(d_{j,k}) = (1-\alpha_2)\, d_{j,k} + \alpha_2\, \tilde d_{j,k}\]
Probe averaging step \(\mathbf{G}^P\) the plain mean over positions \[\bar d_k = \frac{1}{J} \sum_j d_{j,k}\]

3. One iteration

Algorithm 1 of the 2025 paper. Each line is tagged local when every position is handled on its own, or global when it needs a sum over all positions.

localw ← FI(v)each position fits its own data
globalz ← GI(2w − v)one scatter-add over all j, divide by Λ, one gather
localv ← v + 2ρ (z − w)Mann update
xfor each mode k:blind case only
localrk ← FPk(sk; z)each position refines its own probe, using its consensus patch zj
globaluk ← GP(2rk − sk)one mean over all j
localsk ← sk + 2ρ (uk − rk)Mann update
xadd a mode if scheduledfrom the residual intensity; rescale so the total energy is unchanged
xoutput: x̂ = weighted average of v;  d̂k = mean of sk

Every pass has the same shape:

localeach position: its own \(y_j\), its own state row, the current consensus
→
globalone sum over all positions, then broadcast back
→
localeach position updates its own state row

Once per iteration for the patches, and once more per mode for the probes when the probe is estimated. That is the entire communication pattern.

4. Initialization

Two formulas. The probe first, from the mean back-transformed data, propagated a chosen distance \(z\) by Fresnel propagation \(U\):

\[ d^{(0)} = U_{\eta,z,\Delta_x}\left\{ \frac{1}{J}\sum_j (P_j \mathbf{1})^{-1}\, \mathcal{F}^* y_j \right\} \]

Then the object, so that each patch has the right scale:

\[ x^{(0)} = \Lambda_0^{-1} \sum_j P_j^T \left( \frac{\|y_j\|}{\|d^{(0)}\|}\, \mathbf{1} \right), \qquad \Lambda_0 = \sum_j P_j^T P_j \]

A new mode comes from the residual intensity the current modes do not explain, \(I_j - \sum_k |\mathcal{F} D_k x_j|^2\), back-transformed, divided by the patch, averaged over positions, and Fresnel propagated; then all modes are rescaled so the total energy is unchanged.

5. The facts that matter for code

  1. Every pass is local, global, local. The local maps need only their own \(y_j\), their own state row, and the current consensus. The global step is one sum over \(j\). This is what lets the data stream through in batches and across GPUs without changing the answer.
  2. The state is as large as the data, times \((1+K)\). The old code keeps \(\mathbf{v}\) and every \(\mathbf{s}_k\) in memory at once. For integrated-circuit scans that is what does not fit, so where \(\mathbf{v}\) and \(\mathbf{s}_k\) live is the first design question, not an afterthought.
  3. The averaging step is scatter-add, divide by coverage, gather. Nothing else touches the whole image. \(\Lambda_k\) is itself a scatter-add of \(|d_k|^\kappa\), recomputed when the probe changes.
  4. The probe step uses the consensus patch \(z_j\), not \(v_j\). So the probe pass needs the patches from the image pass of the same iteration: either kept per position, or regathered from \(\bar x\).
  5. The physics is in three places only: \(P_j\) (positions), \(\mathcal{F}\) (far-field propagation), and \(D_k\) (the probe). Everything else is arithmetic on patches.
